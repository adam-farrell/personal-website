## Writing a post

Posts are Markdown files in `src/data/post/`. Add a file, give it a title and `publishDate` in the frontmatter, and it appears on the blog, the homepage and the RSS feed.

To add pictures, put them in `src/assets/images/` and reference them with standard Markdown image syntax using a relative path, such as `../../assets/images/photo.jpg`. Astro resizes and converts them to modern formats at build time.

## Drafts

Add `draft: true` to the frontmatter to keep a post off the site until it's ready.
